# MISO MENU

Самостоятельное демонстрационное цифровое меню вымышленного кафе MISO Asian Kitchen. Без лендинга, сервера заказов, платежей, аналитики и внешних API. 12 блюд в 6 категориях. Все цены и составы вымышлены; фотографии иллюстрируют подачу.

## Запуск

Самый быстрый вариант: открыть `index.html` в современном браузере. Интернет для меню не нужен: фотографии, шрифты системы и код локальные. При открытии через file:// браузер может ограничить localStorage и буфер обмена; интерфейс сообщит об ограничении и позволит скопировать текст вручную.

Рекомендуемый вариант с установленным Node.js:

```sh
cd miso-menu
node serve.cjs
```

Открыть http://127.0.0.1:4173. Из родительского каталога можно запустить `node miso-menu/serve.cjs`: сервер всегда использует папку самого проекта, а не текущую рабочую папку. Не открывайте каталог через file:// и не запускайте общий сервер с листингом вместо сервера меню. Остановка — Ctrl+C. Никаких npm install и сборки. Сервер предназначен только для локального просмотра и слушает loopback.

## Возможности

- Горизонтальные категории и поиск по названию сразу во всех категориях.
- Фотокарточки, описание, состав и аллергены в модальном окне.
- Добавление, уменьшение количества, удаление, итог, фиксированная корзина.
- Сохранение корзины в localStorage, валидация повреждённых данных и ограничение 99 порций одной позиции.
- Имя, комментарий, самовывоз / в заведении; формирование и копирование демонстрационного заказа.
- Клавиатурный фокус, подписанные поля, нативные dialog с Escape и удержанием фокуса, reduced-motion, запасная картинка.

Имя и комментарий существуют только в памяти текущей страницы. Корзина сохраняется локально в браузере. Никакой заказ не отправляется; формирование и копирование не очищают корзину. Для очистки удалите позиции.

## Адаптация под клиента

1. `config.js`: name, subtitle, logo, accent. Для нового клиента задайте отдельный storageKey, например `sakura-cart-v1`. Меняйте версию ключа при несовместимой замене каталога.
2. `menu-data.js`: категории, блюда, цены (целое число рублей), вес, описания, аллергены, пути фотографий, необязательные бейджи tag. Каждый id — уникальная постоянная строка из латинских букв, цифр и дефиса. category должен совпадать с id категории. Не используйте один id для разных блюд.
3. `styles.css`, блок `:root`: молочный фон, текст, линии, цвет акцента. Акцент config.js имеет приоритет над CSS. Сохраняйте достаточный контраст текста.
4. `assets/logo.svg`: замените логотип; путь к нему задаётся в config.js. Также обновите favicon в index.html.
5. `index.html`: компактная шапка, слоган и название в подвале, description и noscript. Эти редакционные тексты оставлены в HTML для удобства изменения.
6. Фотографии замените в `assets/`, рекомендуемая ширина 900–1200 px. Укажите источники и права в `assets/photo-sources.json` и `PHOTO-LICENSE.md`.

Названия и описания экранируются при выводе. Пути изображений и id — доверенные настройки разработчика, не пользовательский ввод. После изменения цен сумма пересчитывается по актуальному каталогу. Не добавляйте в статические файлы секреты или API-ключи.

## Бесплатная публикация и QR

GitHub Pages позволяет публиковать статические страницы из публичных репозиториев на GitHub Free:

1. Создайте публичный репозиторий и загрузите **содержимое** папки miso-menu в корень. index.html должен быть на верхнем уровне. serve.cjs можно не загружать.
2. В Settings → Pages выберите Deploy from a branch → main → /(root), сохраните.
3. После публикации скопируйте URL из Pages → Visit site. Все пути относительные, меню работает и в подпапке репозитория.
4. Используйте этот постоянный HTTPS-адрес в QR-коде. Например, в браузере с функцией «Создать QR-код для страницы». Проверьте QR телефоном перед печатью. Адрес localhost для QR посетителей не подходит.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Альтернатива — загрузка папки через Netlify Drop (лимиты выбранного тарифа проверяйте перед публикацией): https://docs.netlify.com/deploy/create-deploys/#drag-and-drop

Внешняя публикация в рамках этой поставки не выполнялась. Сборка не требуется, каталог публикации — папка с index.html. На HTTPS доступен Clipboard API; при запрете буфера предусмотрено ручное копирование.
